# NAVOI — A City in a Different Time

An English-language, responsive digital presentation about Navoi, Uzbekistan. Built with plain HTML, CSS and JavaScript — no build step or dependencies.

## Run locally

Open `index.html` in a browser. Keep `styles.css` and `script.js` in the same folder.

## Publish with GitHub Pages

1. Create a repository and upload all four project files to its root.
2. Open **Settings → Pages**.
3. Under build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

## Features

- Responsive editorial layout for phones and desktops
- Presentation mode with arrow-key navigation and Escape to exit
- Scroll progress and reveal animations
- Place photography and portraits in the people section
- No external links are used as navigation controls; all site navigation stays inside the presentation

## Images

Some photographs load from external image hosts, so an internet connection is required for those images to appear. If you publish the project publicly, review each image's licensing and attribution requirements. For the most reliable GitHub Pages version, download images you have permission to use into an `assets/` folder and update the image paths to local files.
